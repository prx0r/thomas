# Video structure — universal beats + lane overlays (every video, every house)

## Universal (all videos, no exceptions)

1. **Cold open** — one striking line/image/number, attributed. No preamble, no branding.
2. **Settle** — place the listener (where/when in the story, or step in the method).
3. **Walk** — one thread, in order, at sleep pace. One idea per ~5 minutes.
4. **Turn** — the one break: whisper, wonder, or stinger (single, sparse, earned).
5. **Return** — land where we started (door closes, bed found, question kept).
6. **Goodnight** — house sign-off ritual, same words every episode.

Runtime grammar: pilots ~2min (166–216w) prove beats; E01s ~10min prove stamina;
readouts run as long as the text (chunked ≤14k). Black screen unless the house
has a draw preset; art still doubles as thumbnail.

## Lane overlays (additive, in order)

- **Singularity**: cold number → the map (whose, stamped) → walk the spine →
  compare line → goodnight. (timeline-spine.md)
- **Track-record**: dated quote → grade → implication → pending revisit. (A/B)
- **Tales**: hook → beats in order → softened wonder → tomorrow-hook.
- **Diaries**: date spoken → day lived → sensory detail → sign-off ritual.
- **Lore (incl. silicon dreams)**: primer → one slow thread → place-on-spine line
  → settle close. Synthesis only, no clips/assets.
- **Guided (rites/monk)**: settle → descend/count → stay → return+bowl/bell.
- **Trades**: lay out → steps in order, safety-exact → test → done.
- **Lectures (words/papers)**: question → walk → one idea → drift-out.
- **Comfort**: greet → small good things → morning-you → whisper close.
- **Freshness**: ritual open → 5 stories → sleep-on-that close.
