# resources — shared source library

Everything any essay in this repo is allowed to quote lives here, or is
pointed to from here. An essay's `RESOURCES.md` draws from these shelves;
its references section lists which shelf items it actually used.

## Rules

- **Short quotes only** (a line or a paragraph, never chapters). Full books
  stay where they are; each shelf notes where its full text lives on this box.
- Every quote carries **provenance**: author, work, section/page, and how it
  was verified (local text read, public translation cross-checked, etc.).
- Owner's own lines never live here. This shelf is other people's words only.
- When an essay needs a source not yet shelved, shelve it first with
  provenance, then cite it. No drive-by citations straight into essays.
- Copyrighted works: quote briefly with buy/link pointer. Free texts
  (old suttas, author-free PDFs): link freely.

## Shelves

- `suttas/` — Pali canon formulas in public translations (Bodhi, Thanissaro,
  Nanamoli). Free to quote; cite by standard number (SN 15.1, MN 9...).
- `nanavira/` — Ñāṇavīra Thera, Clearing the Path / Notes on Dhamma (1960-65).
  Full text: Path Press volume; key note read verbatim on this box.
- `nanananda/` — Bhikkhu Ñāṇananda, Nibbāna: The Mind Stilled (33 sermons).
  Full text: Library Edition PDF on this box
  (`spirit-directory/gochema/library/nanananda/`).
- `analayo/` — Bhikkhu Anālayo, Rebirth in Early Buddhism and Current Research
  (Wisdom 2018) + lecture course. Full text on this box for study; quote
  briefly, point buyers at Wisdom.
- `levin/` — Michael Levin lab, developmental bioelectricity + ingressing minds.
  Public papers; cite paper + year, summarise findings in plain words.
