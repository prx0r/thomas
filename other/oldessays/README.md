live, (b) what they are, (c) what they're useful for. Templates for
video creation are marked **[TEMPLATE]**.

## THE WORKFLOW (how it all connects)

```
ESSAY (the content)
  ← frontier docs (what the text says, graded)
  ← tractatus/AM0 (the rigorous arguments)
  ← the 50-essay companion (the roadmap + structure)
  → what-the-heck-is format (the essay form)

VIDEO (the render)
  ← essayviz core (the pipeline: storyboard → pack → render)
  ← film-pack structure (visual_program.json: thesis/palette/entities/
     operators/shots — the uniqueness guarantee)
  ← SPANDA 6D vector + RASA framework (the visual-philosophy grammar)
  ← the 600+ render scripts (the material library)
  → check-uniqueness.py gate (the quality check)

PUBLISH (the site)
  ← the ochema-site pipeline (fixed, badges, works.json)
```

**The rule that makes it all work:** every essay starts from a claim
file (source → status → mapping → room), and every video starts from
a visual program (thesis → palette → entities → operators → shots) —
never from a template render. That's what the two GOOD films did, and
that's what the 27 NOT-GOOD ones didn't.
