# other — everything that is not the piece

* `resources/` — shared source library (shelves essays cite from).
* `scripts/` — Fish `.drama.txt` feed builder (`build.py` + `BEATS.md` + `FORMAT.md`).
* `skills/` — essay-sharpening method used every ai round.
* `oldessays/` — archive. Previous engine, blueprints, review bundles,
  thumbnails, audio tests. Kept for reference, not part of the
  ramble → essay → audio pipeline. Heavy (~450M); split out if it
  starts slowing clones.
