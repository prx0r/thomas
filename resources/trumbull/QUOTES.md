## T1. Not stored, but in time — Trumbull, IAI 17 Nov 2025 ("Memory is not
stored in the brain")

"Memory is not stored in the brain but unfolds in time." / "If we assume
from the start that everything mental must be reducible to something
physical, then we close the possibility of understanding the mind on its
own terms." / "The attempt to reconstruct what are fundamentally fluid,
dynamic movements of the mind through step-by-step calculations will only
ever be a mimicry." Status: VERIFIED (box file 01-memory-not-stored,
IAI free portion + reprint closings). Use for: storage metaphor is only a
metaphor; correlation is not containment (footprints don't store walking).

## T2. Overflow — same talk, closing line

"Because the past overflows the present, memory overflows the brain; and
because memory overflows the brain, mind overflows the body." / Lesions

recollections themselves (stroke recovery, paradoxical lucidity in
Alzheimer's cited). Status: VERIFIED (box file). Use for: brain as
facilitator, not container — then pair with Analayo A3 as the check.
