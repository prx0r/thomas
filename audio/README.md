# audio — finished reads, mirrored on essays/

One folder per topic, matching `essays/` and `rambles/`:

```
audio/samsara/   <- rambles/samsara1.md + essays/samsara/ESSAY.md
audio/nibbana/   <- rambles/nibbana1.md + essays/nibbana/ESSAY.md
audio/rebirth/   <- rambles/rebirth1.md + essays/rebirth/ESSAY.md
```

Each topic holds exactly two renders when they exist:

* `<topic>1.mp3` — the ramble read, verbatim from `rambles/<topic>1.md`
* `ESSAY.mp3` — the chosen final essay, verbatim from `essays/<topic>/ESSAY.md`

`ESSAY.md` is the chosen final by definition. Snapshots
(`<topic>essayai1.md`, `ai2`, …) never render directly.

Scripts that feed Fish live in `other/scripts/` (`.drama.txt`
verbatim builds). Nothing here is generated by an agent calling an API.
Renders land here by hand at voice lock.
